# 악보 → 구조화 데이터 변환 도구 조사 (Audiveris/Qwen3-VL 외)

- 조사일: 2026-09-29
- 이미 시험함: **Audiveris**(전통 OMR, key·박자·마디는 정확하지만 가사·코드는 크게 손실), **Qwen3-VL-4B**(비전 LLM, 가사 CER 0.737)
- 목적: 이 두 갈래 외에 다른 변환 방식이 있는지 확인
- 원문: [sources/claude-other-tools.md](sources/claude-other-tools.md) · [sources/grok-other-tools.md](sources/grok-other-tools.md)

## 결론
**두 조사 모두 같은 결론입니다: 지금 쓰는 조합(구조는 Audiveris, 가사·코드는 Qwen3-VL)을 뒤집을 만한 도구는 없습니다.** 다만 **API로 자동화할 수 있는 유일한 상용 도구(Opuscan)**를 하나 찾았습니다.

## 유일하게 시험해 볼 가치가 있는 것: Opuscan (Flat.io)
- **한국어 가사를 명시 지원한다고 밝힌 유일한 도구**입니다. 변환 전에 언어를 한국어로 지정할 수 있고, 음절이 절에 맞춰 정렬된다고 광고합니다.
- **실제 REST API가 있습니다** (`POST /v2/omr/jobs`). 조사한 도구 중 GUI 없이 자동화 파이프라인에 넣을 수 있는 유일한 곳입니다.
- 2026년 6월부터 **자체 모델**을 쓴다고 발표했고, 이전에 쓰던 제3자 엔진(Audiveris 계열로 추정)을 뺐습니다.
- 가격은 페이지당 과금, 30페이지에 약 $9.99. 구독 없음.
- **주의**: 한국 CCM 리드시트(오선+코드+한글 가사+Verse/Chorus+반복기호)로 실제 검증된 사례는 없습니다. 광고만 있고 실측은 없습니다.

## 학술 연구 중 새로 나온 것
- **ISMIR 2025, "Optical Music Recognition of Jazz Lead Sheets"** (arXiv 2509.05329) — 멜로디+코드+가사 리드시트를 다룬다는 점에서 형태가 가장 비슷함. 단, **가사는 다음 과제로 미룸**(이번 논문은 처리 안 함), 필기 재즈 악보 대상, 한글 없음. 코드·가중치는 공개됨.
- **LEGATO 2** (arXiv 2607.05769) — Qwen3-VL 대안 가능성 있는 멀티모달 모델. 제목·주석은 인식하지만 **음절 단위 가사는 아니고, CJK도 아님**. 코드는 "출판 시 공개" 상태라 아직 못 씀.
- MEI 형식, ABC 표기법으로 가는 이미지 변환 경로는 상용 도구가 없음. 둘 다 추천하지 않음.

## 한국 시장 자체가 빈 자리
- 교회 소프트웨어(WorshipTools Charts 한국어판 등)는 **SongSelect·PraiseCharts·PDF·ChordPro를 가져오기만 하지, 사진 악보를 직접 변환하지 않음**.
- 악보가게 같은 곳은 사람이 손으로 정서(浄書)하는 서비스.
- 한국어 특화 악보 디지털화 업체는 찾지 못함.

## X에서 확인한 실제 시도 (2026.09)
- 한국인 개발자 한 명이 합창 악보를 Audiveris로 시도 → **마디가 빠지고 박자가 깨짐**. 유료 OMR도 다성부 분리에 실패.
- 결국 **비전 모델로 음표를 JSON으로 뽑고 → MusicXML로 변환 → 오디오와 대조**하는 방식을 직접 만들어 씀. 이건 우리가 이번에 검증한 접근(구조는 OMR, 나머지는 비전 모델)과 방향이 같습니다.
- 그 사람도 **한글 노래는 음절이 음표에 연결이 안 돼서 실패**했다고 밝힘.
- 찬양·CCM 진영에서 코드+가사 스캔에 성공했다는 사례는 X에서 하나도 찾지 못함. 2026년 9월 찬송가 스캔 시도도 "꽤 심하게 실패"했다는 언급만 있고 도구명은 없음.

## 다음 단계 제안 (우선순위)

3. LEGATO 2는 코드 공개 후 재검토
