# lab: 연구 지도

가설 → 실험 → 결과 → 사실을 노드와 관계로 관리한다. 기능과 도구도 노드다. 마크다운 파일이 원본이고, 서버가 요청마다 읽어 지도를 그린다 (생성 파일 없음).

```
python3 _server/serve.py    # → http://127.0.0.1:8000 (md를 고치면 새로고침)
python3 _server/graph.py    # 노드 수·내용 규칙 경고만 확인
```

## 파일 (= 뷰어 사이드바)
```
<기능>/feature.md                 기능 (예: to-bpm). 현재 상태·쟁점·결정
<기능>/hypotheses.md              그 기능의 가설·실험·결과·사실 전부 (아래 형식)
<기능>/<가설 제목>/<실험 폴더>/      실험의 코드·LOG, kernels.json(커널 설정)·kaggle/(커널 코드) (실험 머리말의 where)
<기능>/_survey/                   조사 문서·원문 (가설이 아닌 폴더는 _ 로 시작)
catalog.md                        공유 노드: 도구 · 데이터셋 · 단계 · 지표
_server/kaggle.py                 Kaggle 커널 올리기: 실험 폴더 kernels.json + kaggle/<코드>.py
_data/<세트>/                     데이터 수집 코드 (데이터 원본은 Kaggle)
_server/                          로컬 서버: 연구 지도(graph.py + viewer.template.html) · Test 페이지 · 음원
_notes/                           공통 조사·자원 목록
```

## 형식
노드 하나 = 제목 줄 + 머리말 한 줄(`키: 값 · 키: 값`, 있으면) + 본문(있으면). 목록 값은 `[a, b]`.

```markdown
## DBN을 붙이면 연속 2박 마디가 사라진다
from: [fact-...]

### experiment-bpm-model-sweep — 찬양·공개 1,502곡에서 BPM 방법 15개 비교
where: lab/to-bpm/DBN을 붙이면 연속 2박 마디가 사라진다/bpm-model-sweep
- 데이터: gtzan · worship-3 · worship-500
- 틀: {조건} → octave-fold → stability(tol=4%) → segment → bars
- 조건 A: beat-this(model=final0|small0)
- 조건 B: beat-this(model=final0) → madmom-dbn
- 지표: tempo-acc(tol=4%) · double-bar-rate
- 기준: B.double-bar-rate = 0%
- 환경: kaggle-t4 × 1 · kaggle-cpu × 2 · 10.5h
- 결과: 성공

### 사실

#### fact-dbn-forces-even-bars — DBN은 템포와 마디 길이가 일정하다고 가정해 반 마디마다 찍히던 downbeat를 한 마디 단위로 묶는다.
kind: 성공 요인 · supports: [DBN을 붙이면 연속 2박 마디가 사라진다] · about: [madmom-dbn, beat-this]
```

| 유형 | 제목 줄 | 내용 |
|---|---|---|
| 가설 | `## 〈한 문장〉` (id = 제목) | 본문 없음. `from: [사실]` (그 사실에서 나온 가설) |
| 실험 | `### experiment-〈x〉 — 〈데이터〉에서 〈대상〉 비교 / 측정 / 채점` | 머리말 `where`, `tests: [다른 가설]`. 본문 = 참조와 값만 쓰는 여섯 줄 + `- 결과: 성공 / 실패` |
| 결과 | (따로 쓰지 않음) | 실험의 `- 결과:` 줄이 `result-〈x〉` 노드가 된다. 같은 가설의 사실을 모두 확정 |
| 사실 | `### 사실` 아래 `#### fact-〈x〉 — 〈한 문장〉` | 본문 없음. `kind: 성공 요인 / 실패 요인 / 부수 사실`, `supports / refutes: [가설]`, `about: [도구·기능]` |
| 도구 | catalog `## 도구` 아래 `### 〈id〉 — 〈이름〉` | `license`, 본문은 짧은 설명 |
| 데이터셋 | catalog `## 데이터셋` 아래 | `n`, `unit`(곡 / 장), `truth`(있음 / 없음), `where`. 본문 없음 |
| 단계 | catalog `## 단계` 아래 | 자체 절차 하나. `tool`(감싼 도구, 있으면). 본문 없음 |
| 지표 | catalog `## 지표` 아래 | `unit`, `better`(높을수록 / 낮을수록). 본문 없음 |

### 실험 본문
본문에는 다른 곳에 정의한 개체의 이름(참조)과 그 값만 쓴다. 설명 문장은 쓰지 않는다. 줄은 이 순서로, 이 여섯 종류(+ 마지막 결과 줄)만 쓴다.

| 줄 | 뜻 | 쓰는 법 |
|---|---|---|
| 데이터 | 대상 | 데이터셋 id를 ` · `로 나열. 같은 절차를 더 큰 세트로 넓혔으면 ` → ` (규모는 마지막 단계) |
| 틀 | 모든 조건에 공통인 절차 (통제 변인) | 단계·도구 id를 ` → `로 잇고, 바꾸는 자리에 `{조건}` 한 번 |
| 조건 X | 바꾼 것 (독립 변인), 한 줄에 하나 | `{조건}` 자리에 들어갈 단계. `값\|값`은 조건을 그만큼 펼친다. 단계가 없으면 `(없음)` |
| 지표 | 잰 것 (종속 변인) | 지표 id(파라미터)를 ` · `로 나열 |
| 기준 | 성공 기준 | `조건.지표 부등호 값`. 펼친 조건 하나만 보려면 `A(feel=auto).지표` |
| 환경 | 실행 환경 | `kaggle-t4 / kaggle-p100 / kaggle-cpu / local × 개수`, 시간 제한 `10.5h` |

- 파라미터는 `이름(키=값, 키=값)`. 생략하면 그 단계의 기본값
- 규모 = 데이터 n 합 × 펼친 조건 수. `graph.py`가 계산해 화면에 보인다 (예: 곡 1,502개 × 방법 15개)
- 결과의 성공 / 실패는 기준을 넘었는지로만 정한다
- 실험 → 도구(사용)는 조건·틀의 단계에서, 실험 → 데이터셋(대상)·지표(측정)는 각 줄에서 계산한다

관계: 기능 → 가설 **포함**(hypotheses.md), 사실 → 가설 **파생**(`from`) · **지지 / 반박**, 가설 → 실험 **검증**, 실험 → 도구 **사용** · 데이터셋 **대상** · 지표 **측정**, 실험 → 결과 **산출**, 결과 → 사실 **확정**, 사실 → 도구·기능 **대상**

- 가설은 제목으로, 기능은 폴더 이름으로, 나머지는 id로 참조한다. id는 전체에서 겹치지 않게 한다
- 변형(final0, small0)이나 설정값은 노드로 만들지 않고 단계 이름 뒤 괄호에 적는다
- `graph.py`가 내용 규칙 위반, 이어지는 대상이 없는 참조, 겹치는 id를 경고로 알려 준다
- 수치·해석은 노드에 쓰지 않고 실험 폴더의 LOG·results에 둔다

## 뷰어
- 왼쪽 사이드바: 기능 → 가설 → 노드 트리. 항목을 누르면 그래프에서 그 노드를 선택하고 가운데로 옮긴다
- 열: 기능 · 가설 · 실험 · 결과 · 사실 · 도구 · 데이터셋 · 지표 (단계는 실험 페이지에서만). 열 안 순서는 이어진 노드끼리 가깝게 자동 정렬
- 노드를 누르면 위아래로 이어진 계보(가설 → 실험 → 결과 → 사실)가 강조되고, 오른쪽에 본문과 관계가 나온다. 도구·기능은 허브라 그 자체를 누를 때만 이웃이 강조된다
- 드래그로 이동, 휠로 확대, 종류 버튼으로 숨기기, 검색

## 작업 규칙
- 연산은 전부 Kaggle에서 한다. 로컬에서는 편집, 문법 확인, CLI만 한다.
- 음원, 악보, 가사는 저작물이므로 git에서 제외한다 (각 실험의 `.gitignore`).
- 데이터(음원·악보 이미지·실험 결과)의 원본은 Kaggle 데이터셋·커널 출력이다. 로컬에는 md·코드와 연구 지도(8000)가 읽는 파일만 둔다. 필요하면 `kaggle kernels output` / `kaggle datasets download`로 받는다. Kaggle 삭제 명령은 `.claude/settings.json`에서 막아 두었다.
