### 3. 쟁점 결정 반영 (사용자와 1문 1답, README "쟁점과 결정")
- 둘 다 출력(주 BPM + 반·두 배), 우선 auto만, **구간별 템포 출력**, ±4% 유지 후 500곡으로 조정, 검증은 공개 데이터셋만, 라이브/스튜디오 구분 안 함, 연속 2박 마디는 사례가 모이면 판단

### 4. v2–v5: 구간별 템포 (`sections`) → `results/v5/`
- 방법: 접은 템포 곡선을 5창 중앙값으로 평활화 → 현재 구간 중앙값에서 ±2% 넘게 4창(16 beat) 연속 벗어나면 새 구간 → 경계 주변 beat 간격으로 앞/뒤 템포가 가장 잘 갈리는 beat로 경계 다듬기 → 같은 템포 이웃 구간 합침
- v2·v3 selftest 실패: 120→96 합성 곡의 경계를 28–29초로 잡음(실제 24초). v4·v5에서 beat를 저장해 확인한 결과 **Beat This!가 26.5초까지 120 간격으로 beat를 계속 찍고, 26.5–29초는 불규칙(600/158/60 BPM 간격), 29초부터 96** → 코드가 아니라 모델이 급격한 템포 전환을 3–5초 늦게 따라감
- selftest 분리: ① 구간 나누기 로직은 정확한 beat를 직접 넣어 경계 24±1초 확인 ② 오디오 경로는 구간 2개·템포 비율 0.8만 확인 → **v5 SELFTEST OK**
- 3곡 결과: 어노인팅 143 (한 구간), 제이어스 69 (한 구간), **마커스 136 (0:00–4:34) → 120 (4:34–끝)**
