# 공통 규칙

## 주석

설명하는 주석은 쓰지 않는다. 이유, 계약, 주의사항처럼 문장으로 풀어 쓰는 주석은 모두 여기에 든다. 코드에서 드러나지 않는 사정이 있으면 이름을 바꾸거나 README 와 규칙 문서에 적는다.

남겨도 되는 것은 다음뿐이다.

- 구조를 보여 주는 짧은 라벨. `# #` 섹션 마커, `# server`, `// Sidebar`, `<!-- composer -->` 처럼 세 단어 이하이고 문장이 아닌 것이다.
- 실행에 필요한 표기. shebang, `# noqa` 같은 도구 지시문이 여기에 든다.

문서 문자열(docstring)도 쓰지 않는다. 모듈, 함수, 클래스 모두 마찬가지다. 잘못된 인자에 보여 줄 사용법은 `sys.exit("usage: ...")` 처럼 출력하는 자리에 문자열로 둔다.

## 커밋 메시지

커밋 메시지는 동작을 나타내는 영어 동사 한 단어뿐이다. 소문자로 쓰고, 범위 표시, 마침표, 본문, 트레일러를 붙이지 않는다. `Co-Authored-By` 같은 도구 표식도 붙이지 않는다.

| 단어 | 쓰는 때 |
|------|------|
| `initialize` | 저장소의 첫 커밋 |
| `add` | 새 파일, 기능, 문서를 들인다 |
| `update` | 이미 있는 것의 내용을 바꾼다 |
| `fix` | 잘못된 동작을 바로잡는다 |
| `remove` | 지운다 |
| `move` | 위치나 구조를 옮긴다 |
| `rename` | 이름만 바꾼다 |
| `refactor` | 동작은 그대로 두고 코드를 고친다 |
| `revert` | 앞선 커밋을 되돌린다 |

한 커밋에 동작이 둘 이상 섞이면 한 단어로 적을 수 없으므로 커밋을 나눈다.

## 적용 범위

주석 규칙은 코드, 셸 스크립트, Dockerfile, compose, `.env`, ignore 파일, HTML 을 포함해 이 저장소에서 우리가 쓰는 모든 파일에 적용한다. `collected/` 아래의 수집물은 상류 원문이므로 예외다.
