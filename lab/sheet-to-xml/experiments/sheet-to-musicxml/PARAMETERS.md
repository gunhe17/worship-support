# 문서별 파라미터 — 목표와 목록

## 목표
악보마다 달라질 수 있는 값은 코드에 박힌 상수가 아니라 **파라미터**로 정의한다. 파라미터는
1. **문서마다 추정**한다 — 그 문서의 이미지에서 직접 잰다(가능하면 진하기 기준 없이).
2. **기본값과 허용 범위**를 가진다 — 추정에 실패하거나 범위를 벗어나면 기본값을 쓰고 그 사실을 기록한다.
3. **근거 데이터가 쌓인다** — 처리한 문서마다 추정값, 사용값, 결과(성공/실패 사례)를 남긴다.
4. **데이터에 따라 조정된다(자가 개선)** — 쌓인 분포와 실패 사례를 보고 기본값·허용 범위·추정 방법을 고친다. 고친 이력과 이유를 이 문서에 남긴다.

최종 목표: 새 악보 유형(해상도, 인쇄 굵기, 스캔·손그림, 워터마크)이 들어와도 상수를 손으로 고치지 않고, 쌓인 데이터로 파라미터가 스스로 맞춰지는 오선 검출.

## 파라미터 항목의 형식
| 칸 | 내용 |
|---|---|
| 이름 | 코드와 기록에서 쓰는 이름 |
| 뜻 | 무엇을 나타내는 값인가 |
| 쓰는 곳 | 어느 단계의 어떤 판단에 쓰이나 |
| 추정 방법 | 문서에서 어떻게 재나 |
| 기본값 / 허용 범위 | 추정 실패·범위 밖일 때의 처리 |
| 근거 데이터 | 기록 위치와 현재까지의 분포 |
| 조정 규칙 | 데이터가 쌓이면 무엇을 보고 어떻게 고치나 |
| 이력 | 날짜·변경·이유 |

## 파라미터 목록

## 측정값 (파라미터가 아님 — 문서마다 재서 길이의 기준으로 씀)
- **줄 간격**: 열마다 위→아래로 선 반응 사이 거리의 최빈값. 대부분의 길이 기준.
- **선 두께**: 찾은 오선의 각 줄에서 선 반응이 위아래로 이어지는 길이(또는 세로 검은 연속 길이의 최빈값). P1의 기준이자, 오선 줄 진하기를 읽는 범위(줄 중심 ± 선 두께의 절반)로 그대로 사용 → 이전 P15 "오선 줄 읽는 두께"는 이 측정값으로 대체되어 삭제.

### P1. 선 두께 한계 (`staff_line_max_thickness`)
| 칸 | 내용 |
|---|---|
| 뜻 | 그 문서에서 오선 한 줄이 가질 수 있는 최대 세로 두께(px, 가로 2000px 작업 이미지 기준). |
| 쓰는 곳 | 1단계 선 반응의 **위아래 비교 범위** = 측정한 선 두께 × 배수(조정할 값은 이 배수 하나), 단 줄 간격의 절반보다 작게. 처음 찾기는 넉넉한 기본값(9px)으로 하고, 선 두께를 잰 뒤 필요하면 한 번 더 찾음. |
| 추정 방법 | ① 여러 비교 범위로 반응을 만들어 "같은 간격 반복 구조"가 가장 뚜렷한 범위를 고름 ② 찾은 오선 줄에서 세로 방향 어두운 연속 길이의 상위 백분위 ③ 대략적 이진화의 세로 검은 run-length 최빈값(OMR 표준; 연한 오선 문서에서는 부정확할 수 있음). |
| 기본값 / 허용 범위 | 기본: 비교 범위 9px에 해당(현재 동작). 범위: 1px 이상, 0.5p 미만(그 이상이면 음표 머리와 구분 불가 → 기록하고 기본값). |
| 근거 데이터 | 아직 없음. 기록할 것: 문서별 추정 두께, p, 사용한 비교 범위, 오선 검출 결과(찾은 수/정답 수, 놓친 오선). |
| 조정 규칙 | 놓친 오선이 "굵은 선 → 반응 약함"이면 상한 쪽 조정, "음표 머리가 줄로 잡힘"이면 하한 쪽 조정. 추정값 분포의 이상치 문서는 따로 모아 확인. |
| 이력 | 2026-10-01 정의(사용자 지정 첫 파라미터). 추정 방법·조정 규칙은 사용자 검토 후 확정. |

### P2. 줄 간격 (`interline_p`)
| 칸 | 내용 |
|---|---|
| 뜻 | 그 문서의 오선 줄 사이 간격(px, 작업 이미지 기준). 거의 모든 허용 범위(띠 폭, 이빨 허용, 잇기 허용, 최소 길이, P1 상한)의 자. |
| 쓰는 곳 | 2–4단계 전체, P1의 상한(< 0.5p). |
| 추정 방법 | **열별 세로 간격의 최빈값**: 열마다 가는 가로선 반응 사이 거리를 모아 가장 흔한 값(2026-10-01 결정). 이전 방식(행별 중앙값 곡선의 자기상관)은 행 집계가 필요하고 기울기·짧은 오선에 약해 폐기. 확인할 것: 덧줄·빔·가사 밑줄 간격이 최빈값을 이기지 않는지. |
| 기본값 / 허용 범위 | 탐색 범위 `p_min`–`p_max` = 현재 상수 6–60px. 100장 실측 9–30px. 추정값이 범위 끝에 붙거나, 2p·p/2 지연이 거의 같은 세기면(배수 혼동) 기록. |
| 근거 데이터 | 100장 문서별 p(struct.json의 interline). |
| 조정 규칙 | `p_min`/`p_max`를 쌓인 실측 분포의 여유 범위(예: 최솟값×0.5, 최댓값×1.5)로 갱신. 배수 혼동·범위 끝 사례가 나오면 그 문서를 모아 추정 방법을 고침. |
| 이력 | 2026-10-01 확정. |

### P3. 행 점수 인정 비율 (`row_score_quantile`)
| 칸 | 내용 |
|---|---|
| 뜻 | 한 행(띠 안의 한 행)을 "선이 있는 행"으로 볼 때, 그 띠의 열 중 몇 %에 선 반응이 있어야 하나. 지금은 중앙값(= 50% 이상 열에 반응 필요). 백분위 q로 쓰면 필요한 비율 = 1 − q. |
| 쓰는 곳 | **3단계 전용** — 띠마다 "이 행이 선이 지나가는 행인가"를 판정해 5줄 빗의 봉우리를 만듦. (2026-10-01 수정: 처음엔 2단계 p 추정 곡선에도 같은 중앙값을 써서 함께 묶었으나, 2단계는 판정이 아니라 측정이라 분리 → 2단계는 행 집계 자체를 없애고 열별 세로 간격 최빈값으로 p를 잼) |
| 추정 방법 | 문서마다 정하기보다 데이터로 정하는 전역값에 가까움. 문서별로는 "음표·글자로 가려진 열 비율"을 재서 조정 가능. |
| 기본값 / 허용 범위 | 기본 q = 0.5(중앙값). 낮추면(필요 비율↑) 글자 가로획이 많은 행을 덜 잡지만 음표가 빽빽한 줄을 놓침(67/100 사례: 길게 이어진 반응만 쓴 극단). 높이면(필요 비율↓) 짧게 끊긴 선도 잡지만 글자·상자 행이 선처럼 보일 위험. |
| 근거 데이터 | 놓친 오선마다 "선이 덮은 비율"(예: 제이어스 마지막 오선 48%, 페이지 기준). 세로 띠 방식에서는 띠 단위 비율로 다시 잴 것. |
| 조정 규칙 | 놓친 오선의 덮은 비율 분포와 오탐(선이 아닌데 잡힌 행)의 덮은 비율 분포 사이에서 q를 고름. 띠 방식 도입 후에는 "가운데 80%" 같은 판정 범위도 이 항목에 포함. |
| 이력 | 2026-10-01 확정. |

### P4. 세로 띠 폭 (`strip_width_k`, 띠 폭 = k × p)
| 칸 | 내용 |
|---|---|
| 뜻 | 3단계에서 페이지를 나누는 세로 띠의 폭. 줄 간격 p의 배수 k로 정함(현재 k = 5). |
| 쓰는 곳 | 3단계 띠별 5줄 빗, 4단계 띠 잇기, 최소 길이(이어진 띠 2개 = 2k·p). |
| 왜 검증이 필요한가 | 좁을수록: 기울기·휨·짧은 오선에 강함(띠 안에서 선이 거의 수평). 대신 띠 하나에 열이 적어 음표 머리·글자에 행 점수가 흔들리고, 최소 길이도 짧아져 우연한 일치가 늘 수 있음. 넓을수록: 행 점수가 안정적. 대신 띠 안에서 기운 선이 여러 행에 번져 이빨 허용(±0.25p)을 넘음. 대략 기울기 θ에서 띠 안 높이 차 = k·p·tanθ < 0.25p → k < 0.25 / tanθ (θ=2°면 k < 7, θ=3°면 k < 4.8). |
| 추정 방법 | 우선 전역값(데이터로 정함). 이후 문서의 기울기·휨 정도를 재서 문서별로 줄이는 방식 검토. |
| 기본값 / 허용 범위 | 기본 k = 5(미검증). 후보 범위 3–8. |
| 근거 데이터 | 아직 없음. 손그림 사례(복음성가)에서 같은 선이 열마다 최대 95px 이동 — 페이지 단위 판정 실패 근거. 8개 띠(폭 250px ≈ 11p)로 나눈 진단 그림에서는 띠마다 5줄이 잡힘. |
| 검증 방법 | k ∈ {3, 4, 5, 6, 8}로 100장 + 인공 변형(회전 1–3°, 휨, 해상도 ½, 일부만 남김)에서 비교: 찾은 오선 수(정답 700), 놓친 오선의 유형, 오선 아닌데 잡힌 수. |
| 조정 규칙 | 놓친 오선이 "기울기·휨"이면 k를 줄이고, 오탐이 "띠 하나 크기의 우연한 일치"면 k 또는 최소 띠 수를 늘림. |
| 이력 | 2026-10-01 확정. |

### P5. 띠 잇기 허용 (`link_tolerance_m`, 허용 = ±m × p)
| 칸 | 내용 |
|---|---|
| 뜻 | 4단계에서 이웃 띠의 오선 조각을 같은 오선으로 이을 때, 두 조각의 위치(맨 윗줄 y) 차이를 얼마까지 허용하나. 현재 m = 0.5(±p/2). |
| 쓰는 곳 | 4단계 띠 잇기. |
| 왜 검증이 필요한가 | 작으면: 기운·휜 오선에서 이웃 띠의 조각이 허용 밖으로 벗어나 한 오선이 여러 조각으로 끊김. 크면: 한 칸(p) 어긋난 조각, 즉 위아래로 한 줄 밀린 빗(덧줄·테두리 때문에 4/5로 잘못 맞은 빗)까지 이어 붙여 오선 위치가 한 줄 틀어질 위험. m < 1이어야 "한 줄 밀림"과 구분 가능. |
| 관계 | P4와 짝: 띠 사이 높이 변화 ≈ k·p·tanθ(+휨). 잇기가 끊기지 않으려면 m·p > k·p·tanθ → m > k·tanθ (k=5, θ=3°면 m > 0.26). |
| 추정 방법 | 우선 전역값. 이후 문서의 띠별 오선 위치 변화량(기울기·휨)을 재서 문서별로 정하는 방식 검토. |
| 기본값 / 허용 범위 | 기본 m = 0.5(미검증). 후보 범위 0.25–0.75. |
| 근거 데이터 | 아직 없음. 손그림(복음성가) 같은 선이 열마다 최대 95px(≈4.3p) 이동 — 페이지 전체 기준이며 이웃 띠 사이 변화는 그보다 훨씬 작음(측정 예정). |
| 검증 방법 | P4와 함께 격자 비교(k × m) — 100장 + 인공 변형에서 끊긴 오선 수(한 오선이 둘 이상으로 나뉨), 한 줄 밀려 이어진 수, 찾은 오선 수. |
| 조정 규칙 | 끊김이 많으면 m을 늘리고, 한 줄 밀림이 생기면 m을 줄이거나 잇기 전에 빗을 이웃 띠에 맞춰 다시 정렬. |
| 이력 | 2026-10-01 확정. |

### P6. 최소 이어진 띠 수 (`min_linked_strips_n`)
| 칸 | 내용 |
|---|---|
| 뜻 | 4단계에서 이어진 띠가 몇 개 이상이어야 오선 하나로 인정하나. 현재 n = 2. 실제 최소 길이 = n × (띠 폭 k·p). |
| 쓰는 곳 | 4단계 오선 인정. |
| 왜 검증이 필요한가 | 작으면: 띠 한두 개 크기의 우연한 일치(코드 다이어그램, 글자 가로획 묶음, 표 테두리)가 오선으로 잡힐 위험. 크면: 짧은 오선(마지막 줄, 한두 마디짜리 조각 오선, 코다·인트로 조각)을 놓침. |
| 관계 | P4와 곱으로 실제 길이가 정해짐(k=5, n=2 → 10p ≈ 한두 마디). 그래서 "띠 수"가 아니라 "p 단위 길이"로 정의를 바꿀지도 함께 검토. |
| 추정 방법 | 전역값(데이터로 정함). 짧은 실제 오선들의 길이 분포가 하한 근거. |
| 기본값 / 허용 범위 | 기본 n = 2(미검증). 후보 범위 1–4. |
| 근거 데이터 | 가장 짧은 실제 오선: 제이어스 「오직 예수」 마지막 줄(페이지 폭 약 49%, ≈ 55p — 넉넉히 통과). 마커스 「주의 이름 높이며」 위쪽 인트로 조각 오선(상자 안 작은 오선)은 길이·줄 간격 측정 예정. |
| 검증 방법 | P4·P5와 함께 100장 + 인공 변형("일부만 남김" 변형으로 길이를 줄여 가며)에서: 놓친 짧은 오선, 오선 아닌데 잡힌 짧은 구조의 수와 길이. |
| 조정 규칙 | 오탐이 생기면 그 구조들의 길이 분포 위로 n을 올리고, 짧은 오선을 놓치면 그 길이 아래로 내림. 두 분포가 겹치면 길이 대신 다른 확인(선 두께, 세로선 밀도)이 필요하다는 신호. |
| 이력 | 2026-10-01 확정. |

### P7. 유효 잉크 범위 (`ink_range`)
| 칸 | 내용 |
|---|---|
| 뜻 | 5단계에서 "악보 잉크"로 인정하는 회색값 범위 [0, T). T는 찾은 오선 줄의 회색 분포로 문서마다 정함. 이 범위를 정하는 값들이 하위 파라미터. |
| 하위 파라미터 | **q_line** 오선 줄 회색에서 쓸 백분위(현재 0.9 — 오선 중 연한 쪽) · **α** 연한 쪽에서 종이 쪽으로 더 가는 비율(현재 0.35) · **T_floor** 하한(현재 min(Otsu, 150) — 깨끗한 악보에서 기존과 같게) · **δ_paper** 상한 여유(T ≤ 종이 회색 − δ, 현재 없음) · **q_paper** 종이 회색 백분위(현재 0.9). |
| 식 | T = clip( 오선 회색 q_line + α × (종이 − 오선 회색 q_line),  T_floor,  종이 − δ_paper ) |
| 쓰는 곳 | 오선에 이어진 음표를 따라가 오선 영역을 오려낼 때. (행 사이 빈 띠 찾기는 T_floor만 사용 — 높은 T가 흐린 가장자리로 빈 띠를 메운 사례) |
| 왜 검증이 필요한가 | T가 낮으면: 연한 오선·꼬리·마디선이 오선 영역에서 빠짐(③ 소실, 예수전도단·힐송·아가파오). T가 높으면: 워터마크·흐린 가장자리·종이 얼룩이 잉크로 들어와, 워터마크를 타고 가사가 오선에 붙거나 행이 합쳐짐. 워터마크가 오선만큼 진하면 이 범위로는 가를 수 없음(→ "확인 필요" 표시). |
| 근거 데이터 | 6장 시험: 문서별 T 148–208, ③ 소실 0. 100장: 오선 위 분포로 정한 T가 기존 0단계 T와 95장에서 ±5 이내(최대 차 −9.8). 분포만의 기준은 실패(가는 획을 회색 쪽으로 보냄). |
| 검증 방법 | 문서별로 (a) 오선 줄 픽셀 중 T 안에 드는 비율(높아야 함), (b) 워터마크·종이 쪽 픽셀 중 T 안에 드는 비율(낮아야 함 — 워터마크 악보는 영역 표시 필요), (c) 오선 영역에 가사·글자가 끌려온 사례 수, (d) ③ 소실 비율. q_line·α 격자(예: q_line ∈ {0.8, 0.9, 0.95}, α ∈ {0.2, 0.35, 0.5}). |
| 조정 규칙 | ③ 소실이 남으면 α 또는 q_line을 올리고, 워터마크·글자 끌림이 생기면 내리거나 δ_paper를 둠. 문서별 T가 이웃 문서들과 크게 다르면(이상치) 따로 모아 확인. |
| 이력 | 2026-10-01 확정. |

## 파라미터가 아니라 규칙으로 정리한 것 (2026-10-01)
- **오선 간 최소 거리 → 삭제.** 두 후보가 줄을 공유하거나 세로로 겹치면 같은 오선, 더 고르고 강한 쪽만 남김. 겹치지 않으면 별개.
- **가로 구간 끝 판정 → 삭제.** 끝 = 이어진 마지막 띠, 그 띠 안에서는 "5줄 중 4줄 이상이 사라지는 열"(약해도 되는 줄 수 파라미터를 재사용). "한 줄이라도 끝나면 끝"은 연한 줄·잠깐 끊긴 줄에서 오선 전체가 잘려서 쓰지 않음.
- **p 추정용 행 집계 → 삭제.** 줄 간격은 열별 세로 간격의 최빈값으로 잼.
