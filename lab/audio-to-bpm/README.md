# 2. Audio → BPM

곡 오디오를 넣으면 **BPM**(대안 후보 ×½·×2 포함), **박자**, **템포 안정성**을 돌려준다.

## 현재 상태
- 실험: [_common/experiments/audio-analysis-test](../_common/experiments/audio-analysis-test/) (3곡, key·송폼과 같이 측정). 원시 결과는 [RESULTS.md](../_common/experiments/audio-analysis-test/results/RESULTS.md)에 있다. **아직 채점하지 않았다.**
- 방법: Beat This!(DBN 없이)로 beat를 잡고 median 간격으로 BPM을 낸다. librosa로 비교하고, 구간별 BPM도 같이 낸다.
- 관찰: 곡 전체 BPM은 안정적으로 나오지만, **구간별 BPM은 반·두 배 오류(octave error)가 잦다**. 예를 들어 같은 곡 안에서 69.8과 136.4가 섞이고, 60과 120이 섞인다. 반·두 배 판정 규칙이 필요하다.

1. ~~정답 BPM 기준~~ → **결정(2026-10-07): 둘 다 출력.** 주 BPM 하나 + 반·두 배 값을 함께 내고, 채점은 둘 중 하나만 맞아도 정답(Acc2)

3. ~~범위 응답이 템포 전환을 가림~~ → **결정: 구간별 템포를 출력** (예: 136 (0:00–4:32) → 120 (4:36–)). 템포 변동·리타르단도 종지·리타르단도 섹션 분석은 나중에
4. ~~안정 판정 기준~~ → **결정: ±4% 유지, 500곡 결과의 폭 분포를 보고 조정** (구간 나누기에도 같은 기준). 500곡: 폭 4% 326곡 / 8% 403곡 / 12% 443곡이 안정
5. **끝부분 리타르단도·늘임표**: 마커스 끝 107이 범위 하한을 끌어내림. → 3번의 나중 분석(리타르단도 종지·섹션)에서 다룸
### 마디·박자
6. **연속된 2박 마디**: 제이어스 102마디 중 24개가 2박이고 0:25–0:37, 1:00–1:11처럼 연속으로 나옴 → downbeat를 반마디마다 찍는 것으로 보임. 이웃과 합쳐 4박으로 보정할지는 **사례가 더 모이면 판단** (보정 보류). → GTZAN에서 정답 4박을 2박으로 118클립, 1박으로 50클립 (996 중), 찬양 500곡 중 346곡에 연속 2박 마디 — 같은 현상
7. ~~downbeat 정답 대조 없음~~ → **결정: 공개 데이터셋**으로 잰다. GTZAN 996클립: tempo Acc2 0.945 / Acc1 0.818, beat F 0.893, downbeat F 0.789, 박자 0.780 (pop 0.98 / 0.939 / 0.93)
8. **실제 박자 변화 vs 오검출 구분 불가**: 2/4 끼워 넣기, 6/8·3/4 혼동 사례 아직 없음
12. **Beat This!가 급격한 템포 전환을 3–5초 늦게 따라감** (합성 120→96에서 확인, 전환 직후 beat 간격 불규칙). 구간 경계가 몇 초 늦을 수 있음. 실제 곡(필인·리타르단도로 전환)에서도 그런지는 사례를 보고 판단
13. **셋잇단·셔플 박 단위 혼동**: 찬양 500곡의 구간 전환 536개 중 126개가 ×4/3·×3/4 → 실제 템포 변화가 아니라 박 단위를 바꿔 잡은 것으로 보임. 구간 나누기에서 4/3·3/4 비율을 반·두 배처럼 접을지 미정
