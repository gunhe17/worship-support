## Failures / Recovery
V11 MySQL DDL is atomic per ALTER, not across the migration's two ALTERs. The upgraded fixture test now forces export_artifact failure after membership_end was installed, then proves repeat DROP/re-add and repair/resume. Never invoke repair/correction automatically on deployed data.
H3: SnakeYAML emitted repeated empty-list aliases exceeding its ordinary safe parser limit. Candidate output now clones the tree before YAML rendering so the shipped contract has no anchors/aliases; parser protections were not relaxed. Spring ResponseStatus aliases require merged annotation lookup to derive the actual success status.
H1: MySQL CHECK 3819 uses SQLSTATE HY000, translated by JdbcTemplate to UncategorizedSQLException rather than DataIntegrityViolationException. Tests require DataAccessException plus root SQLException error 3819 and the exact CHECK name, not unrelated FK/duplicate/connection failures.
- D-01 test-first RED: both new tests failed for the intended missing EDIT authorization, not infrastructure failure. Original implementation allowed generation after VIEWER demotion and successful commit during demotion. Changing only an expected success result would not have resolved these probes; production policy checks were changed at both boundaries.
- Final HTTP review preserves standard 400/404/405/415 responses for missing multipart parts, malformed bodies, unknown routes and unsupported request types, instead of generic 500 errors. Real CSRF rotation and invalid-token rejection are exercised without mock CSRF injection. The isolated HTTP adapter tests require all mock expectations to be declared before requests, or reset between cases.
- Export iteration caught misuse of the token hash helper (limited to 512 characters) for canonical content. Export now hashes UTF-8 content independently; the long Korean PDF regression test exercises multi-page notes. Storage review also found Score's put failure was outside its compensation try: ambiguous put failures now compensate using the unique object key, with dedicated regression coverage.
- Sandbox prevents Docker socket access and DNS resolution. Retry only required local infrastructure/dependency operations with scoped escalation; do not bypass required verification.
- Spring Session JDBC exposes a package-private session implementation; use generic public SessionRepository/Session interfaces rather than inferring that implementation with `var`.
- MySQL JDBC queryForList maps DATETIME to LocalDateTime, not Timestamp. OAuth intent storage explicitly converts UTC LocalDateTime/Instant. Spring Session cookie serializer is configured explicitly; HTTP tests detected the servlet cookie properties alone did not enforce Secure in the test environment.
- Testcontainers stops per-class databases while Spring caches contexts. Use DirtiesContext AFTER_CLASS on MySQL integration classes to close session schedulers alongside their database, rather than leaving cached contexts to run against stopped containers.
- Failure injection through MySQL triggers needs SUPER with binary logging. Compensation tests instead add a temporary CHECK scoped to the test workspace, then remove it in finally; no elevated database privileges or production operations are needed.
